# 🛡️ My Cybersecurity Path

> A hands-on, beginner-to-practitioner cybersecurity learning roadmap.

This repository documents my cybersecurity journey—from core networking and Linux concepts to offensive security, blue teaming, cloud security, GRC, and specialization. It is designed as a living study guide: learn, practise in safe labs, track progress, revise, and build a portfolio along the way.

## 🗺️ Learning roadmap

The interactive notebook is the heart of this repository. It lays out a structured path for studying around **10–15 hours per week**, with estimated time, learning resources, revision checkpoints, practice platforms, certification ideas, and progress tracking.

| Stage | Focus |
| --- | --- |
| Foundation | Networking, Linux, Kali Linux, and Python |
| 1. Core Technical Mastery | Advanced networking, Linux, scripting, and essential tooling |
| 2. Offensive Security | Reconnaissance, vulnerability assessment, web security, and red-team fundamentals |
| 3. Defensive Security | SIEM, log analysis, incident response, malware analysis, and forensics |
| 4. Application & Cloud Security | Web/API, mobile, cloud, container security, and bug bounty practice |
| 5. Advanced Offensive Security | Active Directory, red-team tradecraft, exploit development, and reverse engineering |
| 6. GRC | Governance, risk, compliance, NIST, ISO 27001, and MITRE ATT&CK |
| 7. Specialization | Offensive security, defensive/forensics, or bug bounty |
| Purple Teaming | Detection engineering and red/blue collaboration |

The full path is expected to take roughly **2–3 years** with consistent practice. It is a guide, not a race.

## 🚀 Getting started

1. Clone the repository.

   ```bash
   git clone https://github.com/sg-0601/my-cyber-path.git
   cd my-cyber-path
   ```

2. Install Jupyter Notebook or JupyterLab.

   ```bash
   python -m pip install jupyter
   ```

3. Open the roadmap.

   ```bash
   jupyter notebook roadmap/Cybersecurity.ipynb
   ```

4. Track progress in the notebook using:

   - `⬜ Not Started`
   - `🟡 In Progress`
   - `✅ Completed`
